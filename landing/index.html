Opening it on a Mac

HidraBrowser is not signed with an Apple Developer ID, so macOS blocks it on first launch. On Apple Silicon the message is “HidraNet.app is damaged and can’t be opened” — the download is fine; macOS says that about any unsigned app. Three commands fix it: 

xattr -cr HidraNet.app
codesign --force --sign - \
  HidraNet.app/Contents/Resources/bin/tor/tor
codesign --force --deep --sign - HidraNet.app

The bundled Tor has to be signed on its own, and before the app: --deep does not reach binaries under Resources/. Skip that line and the browser opens but cannot connect — it reports “tor exited with code null”.

The ZIP also contains Start HidraNet.command, which runs all of them for you, and README-macOS.txt with the full walkthrough.

Still blocked? On macOS 15 (Sequoia) and later, right-click → Open no longer works — Apple removed it. Go to System Settings › Privacy & Security, scroll down, and click Open Anyway.

Why not just sign it: signing and notarising requires a paid Apple Developer account. Until the project has one, we would rather explain two commands than claim the app is signed when it is not.
