NOTE ON THE macOS BUILDS CURRENTLY PUBLISHED

The two macOS archives above were produced before a packaging bug was
fixed. They ship a stale Apple code signature that the packaging step
invalidates, so macOS — particularly on Apple Silicon — refuses them
with "HidraNet.app is damaged and can't be opened".

The download is not corrupt. The signature is.

Until they are rebuilt and re-uploaded, open them with:

    xattr -cr HidraNet.app
    codesign --force --deep --sign - HidraNet.app
    open HidraNet.app

Once rebuilt with the fixed packaging script, these two checksums change
and this file has to be regenerated.

NONE OF THESE BUILDS ARE SIGNED OR NOTARISED

There is no Apple Developer ID and no Windows code-signing certificate
behind this release. Verifying the checksum above tells you the file is
the one we published; it does not tell you an operating system will
accept it without complaint. See README-macOS.txt inside the macOS ZIP.
