Install HidraVPN

HidraVPN installs on Windows and Linux; macOS is not supported yet.

HidraVPN is a separate program that protects the whole machine. The browser can install it for you:

  1. it downloads the release the HidraNet maintainers signed, and checks that signature against the key built into this browser before anything else;
  2. it checks every downloaded file against the signed list of files;
  3. it asks your system for administrator rights, once, because only the system may change how the whole machine reaches the network.

How nodes admit this machine

A signed list tells you which nodes exist and who runs them. A node that admits openly needs nothing more: on every Connect it is asked to admit a key made for that one connection, so it cannot tell one of your connections from the next. A node that admits with a pass takes one pass per connection; Settings, Passes asks the list's issuer for them, and the issuer never learns which node a pass is for. A node that admits by hand needs its operator, who hands you an invite to add with the hidravpn command line (nodes add).

Settings

Passes

A node that admits with a pass takes one per connection, and sees a new key every time. Passes come from the issuer the signed list names, against an account: the issuer counts them but never learns which node a pass is for, and a node never learns whose account it came from.

No node on this machine admits with a pass.

The account token is kept by the service on this machine, where only an administrator can read it. Only an administrator can hand it over, since it holds the passes bought on the account, so this page never asks for it: in a terminal, sudo hidravpn passes token FILE (on Windows, hidravpn passes token FILE in a terminal run as administrator). The token it replaces is kept beside it. Anyone with an account on this computer can spend the account's passes.
