HidraVPN

The whole machine through the network, not just this browser. One hop or two through nodes this machine has been admitted to; a kill switch that holds when the tunnel drops. Everything below is read from the service on this machine, not assumed.

Install HidraVPN

HidraVPN is a separate program that protects the whole machine. The browser can install it for you:

  1. it downloads the release the HidraNet maintainers signed, and checks that signature against the key built into this browser before anything else;
  2. it checks every downloaded file against the signed list of files;
  3. it asks your system for administrator rights, once, because only the system may change how the whole machine reaches the network.

Connect

Leak test

Checks what the rest of this machine shows the internet while HidraVPN is connected: the address websites see, whether anything leaves over IPv6, whether a DNS query could leave outside the tunnel, and the kill switch. The address check asks api.ipify.org, directly, as any program on this machine would.

Nodes on this machine

Checking
A signed list tells you which nodes exist and who runs them. A node that admits openly admits this machine when you join it, or when you press Connect with nothing joined yet; a node that admits by hand needs its operator, who hands you an invite for hidravpn nodes add.

Release files

A downloaded HidraVPN file is only worth running if its signature checks out against the release key built into this browser. Choose the file; its .sig must sit beside it.

Updates and removal

Installed version: unknown.

This page does not contain the VPN. It drives the HidraVPN service installed on this machine; with no service, nothing here can connect. Anyone with an account on this computer, and any program they run, can switch HidraVPN on or off for the whole machine. Strong privacy, not anonymity: the service says what each node sees, and so does this page.
